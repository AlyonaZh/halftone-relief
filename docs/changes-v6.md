## 1. Что меняем и зачем

Правки v6 убирают главную жалобу пользователей: непонятно, куда нажать, чтобы эффект начал реагировать на звук. Проект уже опубликован на GitHub Pages; это ТЗ — изменения поверх текущей версии, остальное поведение не трогаем.

| № | Правка | Раздел |
| --- | --- | --- |
| 1 | Метка реактивности становится кнопкой «Звук», у неё всплывающая подсказка | 2 |
| 2 | Подсказка первого входа: тёмная карточка, закрывается крестиком | 3 |
| 3 | Реакция отключается повторным нажатием на выбранный источник, надпись «Отключить реакцию» убрана; расшифровка НЧ / СЧ / ВЧ / КИК | 4 |
| 4 | Три звуковых пресета в верху панели настроек | 5 |

Кнопки реактивности, как и раньше, скрыты, пока нет звука.

**Эталон вида** — экраны «v6 — …» на [холсте дизайна](https://claude.ai/artifact/SwZM5uP6Rc8cQt84V2qDp7): «первый вход: подсказка про звук», «пресеты и окно реакции», «фото без звука: пресеты неактивны». При расхождении с макетом прав текст этого ТЗ. Картинки в карточках пресетов на макете условные.

## 2. Кнопка «Звук» и всплывающие подсказки

Метка рядом со значением слайдера заменяется настоящей кнопкой-пилюлей, понятной без подсказки.

| Состояние | Вид |
| --- | --- |
| Неактивна | Пилюля 24 px, радиус 12 px, фон #17171A, обводка 1 px #3A3A41, текст #D0D0D6 Onest 11 px: иконка частот 12 px + «Звук» |
| Наведение | Обводка #6A6A72, фон #202024, текст #FFFFFF |
| Активна | Белая пилюля #EDEDF0, текст #0A0A0B JetBrains Mono 10 px: иконка + источник («НЧ», «СЧ», «ВЧ», «КИК») |
| Фокус с клавиатуры | Обводка 2 px #EDEDF0 с отступом 2 px |

Зона нажатия — не меньше 44 px по высоте (невидимое расширение), сама пилюля остаётся 24 px.

**Подсказки — общий стиль для всего интерфейса.** Тёмная плашка: фон #1C1C20, обводка 1 px #2E2E34, текст #EDEDF0 Onest 12 px / 1.4, радиус 8 px, ширина до 220 px, со стрелкой к элементу. Появляется при наведении и при фокусе с клавиатуры через \~400 мс, исчезает сразу. Текст подсказки дублируется в `aria-label` (или `aria-describedby`). Светлые подсказки из прошлой версии ТЗ не используем.

| Где | Текст подсказки |
| --- | --- |
| Кнопка «Звук», неактивна | Нажмите, чтобы параметр двигался в такт музыке |
| Пилюля у слайдера, активна | <Расшифровка источника>. Нажмите, чтобы настроить — например «Низкие частоты: бас. Нажмите, чтобы настроить» |
| Кнопки источников в окне реакции | см. раздел 4 |
| Неактивная карточка пресета | Добавьте аудио, чтобы включить пресеты |

## 3. Подсказка первого входа

Один раз за всё время показываем тёмную карточку у кнопки «Звук» слайдера «Сила», чтобы новый пользователь сразу увидел, куда нажать.

**Когда показывается:** впервые появился источник звука (добавлено аудио или загружено видео со звуком), ни одна реакция не включена и подсказку ещё не закрывали.

**Вид** (макет «v6 — первый вход»):

- Карточка шириной 252 px, фон #1C1C20, обводка 1 px #2E2E34, радиус 12 px, тень `0 14px 34px rgba(0,0,0,.6)`, стрелка к кнопке того же цвета с продолжением обводки.
- Сверху строка: заголовок «Оживите картинку звуком» (Onest 14 px, 600, #EDEDF0) и крестик справа (иконка 12 px, #8C8C95, при наведении #EDEDF0 на фоне #26262A; зона нажатия 44 px; `aria-label="Закрыть подсказку"`).
- Под ней текст #A8A8B0, 12 px / 1.45: «Нажмите «Звук» рядом с любым параметром, и он начнёт меняться в такт музыке. Выберите, на что реагировать: басы, середину, верха или бочку.»
- Нумерации и кнопки «Понятно» нет.
- Кнопка «Звук» под карточкой выделена: обводка #8C8C95 и кольцо `0 0 0 3px rgba(237,237,240,.12)`, без размытого свечения.

**Закрывается:** крестиком, клавишей Esc, нажатием на любую кнопку «Звук» или на карточку пресета. После этого не показывается больше никогда — флаг в `localStorage` (`hr.coach.audio.dismissed`); «Сбросить настройки» его не сбрасывает.

## 4. Окно реакции: отключение и расшифровка частот

Реакция отключается повторным нажатием на выбранный источник; надпись-кнопка «Отключить реакцию» внизу окна удаляется.

**Состав окна** (макет «v6 — пресеты и окно реакции»): «Реагирует на» и крестик, кнопки НЧ / СЧ / ВЧ / КИК, слайдер «Глубина». Больше ничего.

**Поведение кнопок источников:**

1. Нажатие на невыбранный источник — выбирает его (как сейчас).
2. Нажатие на выбранный источник — снимает выбор: реакция параметра выключена, зона модуляции и «призрачный» ползунок исчезают, окно закрывается, пилюля у слайдера снова становится неактивной «Звук».
3. Глубина при отключении запоминается: если включить реакцию снова, вернётся прежнее значение.
4. Кнопки — `aria-pressed="true|false"`; Пробел и Enter работают так же, как нажатие.

**Подсказки на кнопках источников** (стиль из раздела 2):

| Источник | Подсказка | На выбранном добавляется |
| --- | --- | --- |
| НЧ | Низкие частоты: бас | Нажмите ещё раз, чтобы отключить |
| СЧ | Средние частоты: голос, гитары | Нажмите ещё раз, чтобы отключить |
| ВЧ | Высокие частоты: тарелки, хай-хэт | Нажмите ещё раз, чтобы отключить |
| КИК | Удары бочки | Нажмите ещё раз, чтобы отключить |

Тексты расшифровок хранятся в одном месте (например, `audio/sources.ts`) и используются и в окне, и в подсказке пилюли у слайдера.

## 5. Звуковые пресеты

Три пресета одним нажатием задают вид эффекта и готовую реакцию на звук; работают только когда есть звук.

**Раскладка.** Новый раздел «ПРЕСЕТЫ» в самом верху панели настроек, над «Аудио»; не сворачивается. Сетка из трёх карточек, 3 колонки, зазор 8 px, высота 64 px, радиус 8 px. В карточке — превью эффекта, без подписи. Название пресета только в `aria-label` («Пресет «Жидкий хром»»), всплывающей подсказки с названием нет.

| Состояние | Вид и поведение |
| --- | --- |
| Нет звука | Карточки неактивны: превью ч/б, прозрачность 0.28, курсор not-allowed, `aria-disabled="true"`; при наведении подсказка «Добавьте аудио, чтобы включить пресеты» |
| Есть звук, пресет не выбран | Тонкая обводка `rgba(255,255,255,.08)`, при наведении `.3` |
| Выбран | Обводка 2 px #EDEDF0 внутри карточки, `aria-pressed="true"` |
| После ручного изменения | Выделение снимается; повторное нажатие снова применяет пресет целиком |

**Что делает нажатие.** Записывает в состояние все параметры эффекта из таблицы ниже и реакцию на звук (источник и глубину) для каждого слайдера; у слайдеров, которых нет в таблице реакций, реакция выключается. Не трогает: файл, аудио, таймлайн, раздел «Цвет», состояние сворачивания разделов. Закрывает подсказку первого входа.

**Когда снимается выделение:** при любом изменении параметра эффекта или реакции, при «Перемешать». Изменения цвета выделение не снимают. При старте и после «Сбросить настройки» ни один пресет не выбран.

**Стартовые значения** (в `presets.ts`; подобрать на глаз и поправить, чтобы образы заметно отличались):

| Параметр | Рельеф | Жидкий хром | Печать |
| --- | --- | --- | --- |
| Сила | 0.42 | 0.85 | 0.15 |
| Масштаб волн | 0.60 | 0.35 | 0.70 |
| Размер точки, px | 9 | 12 | 5 |
| Порог, % | 78 | 82 | 70 |
| Объём | 0.78 | 1.00 | 0.15 |
| Блеск | 0.70 | 1.00 | 0.00 |
| Контуры | вкл | выкл | вкл |
| Количество линий | 6 | 6 | 10 |
| Толщина линий, px | 1.5 | 1.5 | 0.8 |

**Реакция на звук в пресетах:**

| Пресет | Параметр → источник, глубина |
| --- | --- |
| Рельеф | Сила → НЧ, 0.30; Объём → КИК, 0.15 |
| Жидкий хром | Сила → КИК, 0.15; Масштаб волн → НЧ, 0.20; Блеск → ВЧ, 0.10 |
| Печать | Размер точки → НЧ, 0.15; Порог → КИК, 0.10 |

**Превью в карточках.** Рендер текущего файла с параметрами пресета в маленький канвас (длинная сторона \~160 px, без реакции на звук). Обновляется при загрузке файла и не чаще раза в секунду; если рендер дорог (видео на телефоне), — один раз, по первому кадру. Пока превью не готово — карточка #161618.

## 6. Мобильная версия (до 1024 px)

На сенсорных экранах наведения нет, поэтому подсказки заменяются видимым текстом.

- **Подсказки при наведении** не показываются (`@media (hover: hover)`).
- **Окно реакции:** под кнопками источников строка #A8A8B0, 12 px с расшифровкой выбранного: «Низкие частоты: бас · нажмите ещё раз, чтобы отключить». Без выбора — «Выберите, на что реагировать».
- **Неактивные пресеты:** касание показывает под карточками ту же подсказку «Добавьте аудио, чтобы включить пресеты» на 3 секунды.
- **Пресеты** — в начале шторки настроек; в свёрнутом положении шторки их не видно.
- **Подсказка первого входа** показывается, когда шторка открыта на половину или весь экран; карточка на всю ширину шторки минус 16 px с каждой стороны, стрелка к кнопке «Звук». Если шторка свёрнута — ждёт, пока её откроют.
- Все новые элементы — не меньше 44 × 44 px по зоне касания.

## 8. Как внести правки через Claude Code

Правки делаются в отдельной ветке и попадают на сайт после слияния в `main` — GitHub Pages обновится сам.

**Подготовка:**

1. Экспортируйте этот документ в Markdown.
2. Откройте папку проекта `halftone-relief` в Claude Code. Если на этом компьютере проекта нет, начните с запроса «Склонируй https://github.com/<логин>/halftone-relief и открой его».
3. Положите экспортированный файл в проект как `docs/changes-v6.md`.

**Первый запрос в Claude Code:**

```markdown
Прочитай SPEC.md, CLAUDE.md и docs/changes-v6.md — в последнем правки v6 к уже опубликованному проекту. Создай ветку feature/v6-sound-hints. Внеси правки по разделам 2–6 docs/changes-v6.md, не меняя остальное поведение. Пресеты вынеси в presets.ts, тексты расшифровок частот — в один модуль. Затем обнови SPEC.md по разделу 7. Запусти dev-сервер и дай короткий чек-лист для ручной проверки по разделу 8. Ничего не пушь, пока я не проверю.
```

**После проверки:** «Всё проверила, закоммить, запушь ветку и открой pull request в main». Затем на GitHub нажмите Merge — через пару минут обновлённый сайт будет по прежнему адресу. Замечания давайте конкретно: экран, файл, что видно и что ожидалось.

**Критерии приёмки:**

- [ ] Без звука кнопок «Звук» нет, карточки пресетов неактивны и при наведении объясняют почему
- [ ] После добавления аудио один раз появляется тёмная подсказка; закрывается крестиком, Esc, кнопкой «Звук» или пресетом и после перезагрузки не возвращается
- [ ] Кнопка «Звук» читается как кнопка, у неё есть подсказка при наведении и фокусе
- [ ] Повторное нажатие на выбранный источник отключает реакцию; надписи «Отключить реакцию» нет
- [ ] У каждого источника есть расшифровка: подсказкой на десктопе, строкой на телефоне
- [ ] Каждый пресет заметно меняет вид и сразу реагирует на музыку; ручное изменение снимает выделение, цвет пресет не трогает
- [ ] Всё доступно с клавиатуры; на iPhone (Safari) и Android (Chrome) работает касанием
- [ ] Экраны совпадают с макетами v6; SPEC.md обновлён
