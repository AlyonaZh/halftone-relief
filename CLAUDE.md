# Halftone Relief

Браузерный инструмент: фото или видео → полутоновый растр, объёмный рельеф, хромовые блики, жидкое искажение, реакция на звук. Всё считается в браузере, сервера нет.

**Источник истины — [SPEC.md](SPEC.md).** При расхождении с макетами прав текст ТЗ. Макеты v5: `reference/mockups/`, эталон эффекта: `reference/sample.png`.

## Стек

Vite + TypeScript (vanilla, без фреймворка), WebGL2 (GLSL ES 3.0), Web Audio API, MediaRecorder. Интерфейс только на русском, только тёмная тема.

## Структура

- `src/defaults.ts` — все значения по умолчанию и зашитые константы (угол сетки, слияние точек, свет, лимиты, аудио). Подбор вида эффекта — здесь и в шейдерах.
- `src/state.ts` — единое состояние: `settings` (параметры эффекта, сохраняются в localStorage) и `app` (файл, таймлайн, экспорт).
- `src/render/` — `shaders.ts` (проходы: поле искажения → тон+искажение → растр → размытие → свет/хром/контуры/цвет), `pipeline.ts` (рендер превью и экспорта в исходном размере), `gl.ts`.
- `src/media/` — проверка и загрузка файлов (`validate.ts`, тексты ошибок из ТЗ §5), `transport.ts` (воспроизведение, фрагмент in/out, синхронизация аудиофайла).
- `src/audio/engine.ts` — маршрутизация звука, НЧ/СЧ/ВЧ, детектор кика.
- `src/export/` — PNG, SVG (CPU), запись видео, сохранение/«Поделиться».
- `src/ui/` — панель, слайдер с реактивностью, HSB-палитра, таймлайн, панель экспорта, пустое состояние, мобильная шторка.
- `src/main.ts` — раскладка, загрузка файлов, цикл рендера, запись.

## Правила

- Размеры (шаг сетки, толщина контуров) задаются в пикселях исходника; превью масштабирует их через `scale = ширина цели / ширина исходника`, поэтому превью и экспорт совпадают.
- Экспорт PNG/SVG рендерится заново в исходном размере в отдельный фреймбуфер, не копируется из превью.
- Все тексты интерфейса — по ТЗ, дословно.
- Касания: интерактивные элементы ≥ 44 × 44 px на мобильной раскладке (< 1024 px).

## Команды

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + сборка в dist/
```

В dev-режиме в консоли доступен `__hr` (отладка) и `__calib()` / `__cmp(x, y)` — калибровка по референсу: размытый `sample.png` подаётся на вход, `__cmp` показывает референс и рендер 1:1 рядом.

Деплой: push в `main` → GitHub Actions (`.github/workflows/deploy.yml`) → GitHub Pages. `base: './'` в `vite.config.ts` — сборка работает из любой подпапки.
